景表法・広告表示（A〜D）

# 指摘内容 修正後の対応
A 「97%満足度」「3.2ヶ月収益化」「1,200名」に調査根拠の注記がなかった ※1・※2で調査対象・期間・集計方法を明記
B 受講生の声（「月30万円の副収入」等）に個人差免責がなかった 「成果には個人差があり…」免責文を追加
C 返金保証の条件（期間・金額・手続き）が不明確だった 「初回ログインから14日以内、決済手数料除く全額」と明記
D 「残席わずか」という煽り表現に根拠がなかった 「残席は変動します」注記を追加

アクセシビリティ WCAG AA（E/F/G/I/J/K/M）

# 指摘内容 修正後の対応
E 一部テキストのコントラスト比が WCAG AA基準（4.5:1）未満だった CSSでコントラスト修正
F 絵文字アイコンに aria-label がなかった（スクリーンリーダーで意味不明） role="img" aria-label="..." を追加
G スキップリンク（キーボードユーザー向けナビ飛ばし）がなかった <a href="#main-content" class="skip-link"> を追加
I <main> タグがなく、ページ構造がセマンティックでなかった <main id="main-content"> で全コンテンツを囲む構造に修正
J 星評価（★★★★★）がテキストのみで読み上げ時に不明瞭だった aria-label="5点満点中5点" を追加
K フォームの必須項目マーク（*）が aria-hidden されていなかった <span aria-hidden="true">*</span> に修正
M 送信ボタンのアイコン（→）がスクリーンリーダーに読まれていた <span aria-hidden="true"> でラップして読み上げ除外

CV設計・コンバージョン（O/P/Q）

# 指摘内容 修正後の対応
O 最終CTAにフォームがなく、ボタンだけで申込が完結しなかった 名前・メール・プラン選択の <form> を実装
P 申込ボタンにどのプランか識別できなかった href="#contact?plan=standard/premium" でプラン識別を追加
Q 分割払いの目安金額が一切なかった（高額感を和らげる情報が不足） 「月々約21,400円×6回」の目安を注記に追加

パフォーマンス（L/N）

# 指摘内容 修正後の対応
L 未使用のGoogleフォントが <link> に残っていてロードが重かった 不要フォントを削除してロード軽量化
N ヒーローの背景グラデーションが重く、描画ブロックしていた CSSグラデーションを最適化
